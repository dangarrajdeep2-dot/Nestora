🏫 Nestora

Smart College Discovery & Decision Support Platform · Smart Gujarat Hackathon

Nestora is a smart college discovery and decision-support platform designed to help students find, explore, filter, and compare colleges based on important factors such as courses, location, fees, rankings, and other admission-related information.

Our goal is to make the college-selection process simpler, smarter, and more accessible for students.

---

✨ Features

- 🔎 College Search — Discover colleges using relevant search criteria.
  
- 🎯 Smart Filtering — Filter colleges based on available preferences and requirements.
  
- ⚖️ College Comparison — Compare colleges and their key information.
  
- 📍 Location-Based Discovery — Explore colleges based on location.

- 🎓 Course Information — Find colleges offering relevant courses.
  
- 💰 Fee Information — View available fee-related information.
  
- 🏆 Ranking & Performance — Explore available ranking and performance details.
  
- 📱 Responsive Design — Designed to work across desktop and mobile devices.
  
- ⚡ Fast & Modern UI — Built with modern web technologies for a smooth experience.

---

🛠️ Tech Stack

- Frontend: Next.js
- Language: TypeScript
- Styling: Tailwind CSS
- UI: React
- Database: Supabase
- Deployment: Vercel

🚀 Getting Started

Prerequisites

Make sure you have installed:

- Node.js
- npm / yarn / pnpm / bun
- Git

Installation

Clone the repository:

git clone https://github.com/ParmarManthanrajsinh/Nestora.git

Go to the project directory:

cd Nestora

Install dependencies:

npm install

Run the development server:

npm run dev

Open your browser and visit:

http://localhost:3000
